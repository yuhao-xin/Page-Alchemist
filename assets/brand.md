# Notion Alchemist — Brand Guide

> The single source of truth for the project's visual identity. All assets live
> in this folder; the generated HTML/site theme reuses the same tokens.

## Logo

| File | Use |
|---|---|
| `logo.svg` | Master mark — flask + page, transparent background |
| `favicon.svg` | Rounded-square app icon, 64×64 |
| `banner.svg` | Social/README banner, 1200×630 |

Concept: an **alchemist's flask** (transmutation) holding a **document page**
(knowledge), lit by a violet→teal gradient (transformation) with amber sparks
(insight). Clear space: at least 20% of the mark's width on all sides. Never
recolour outside the palette below.

## Palette

| Token | Hex | Usage |
|---|---|---|
| `--na-ink` | `#101223` | Primary text, dark surfaces |
| `--na-indigo` | `#5B5BD6` | Primary brand / links |
| `--na-violet` | `#8B5CF6` | Secondary gradient stop |
| `--na-teal` | `#14B8A6` | Accent, success states |
| `--na-amber` | `#F59E0B` | Highlights, sparks |
| `--na-paper` | `#F7F7FB` | Light surface |
| `--na-muted` | `#6B7280` | Secondary text |

Light theme: paper surfaces, ink text. Dark theme: ink surfaces, paper text.
Accent ordering: indigo → violet → teal; amber reserved for emphasis.

## Typography

- UI / code: system sans stack — `'Segoe UI', 'PingFang SC', 'Microsoft YaHei', system-ui, sans-serif`
- Monospace: `'Cascadia Code', 'JetBrains Mono', Consolas, monospace`
- Headings: 700 weight; body: 400. Never below 14px in generated pages.

## Voice

Confident, precise, a little mischievous — an alchemist, not a corporate
drone. Prefer verbs: *Extract. Cleanse. Reclaim.*
